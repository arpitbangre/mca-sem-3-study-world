## 📝 2. Theory Question Paper Pattern (80 Marks)

* ⏱️ **Exam Duration**: 3 Hours
* 💯 **Total Marks**: 80 Marks (Theory) + 20 Marks (Internal Assessment) = 100 Marks
* 📋 **Question Structure**:
  * Total **5 Questions**, each carrying **16 Marks**.
  * **Q1 to Q4**: Based on **Units 1 to 4** respectively with internal choice within each question (`Question X` OR `Question X`).
  * **Q5**: **Compulsory** question covering questions from all 4 units with equal weightage (No internal choice).

## 📖 3. Detailed Syllabus — Subject Wise

---

### 🤖 Paper 4: 3T4 (CE2-1) — Artificial Intelligence *(Selected Elective)*
* **Credits**: 4 | **Theory Marks**: 80 External + 20 Internal = 100 Marks

#### 🔹 Unit 1: Problem Solving & Search Techniques
* **AI Fundamentals**: AI problems, AI techniques, Tic-tac-toe problem, Question Answering, Problem as state space search, Water jug problem.
* **Production Systems**: Control strategies, Heuristic search, Problem characteristics, Production system characteristics, Design of search programs.
* **Search Algorithms**:
  * Uninformed Search: Depth-First Search (DFS), Breadth-First Search (BFS), Generate-and-Test.
  * Informed / Heuristic Search: Hill Climbing, Best-First Search, Constraint Satisfaction, Means-Ends Analysis.
  * Optimal Search: A* Algorithm, AO* Algorithm.

#### 🔹 Unit 2: Knowledge Representation & Logic
* **Knowledge Representation (KR)**: Representations and mappings, Approaches & Issues in KR.
* **Predicate Logic**: Representing Instance and Isa relationships, Computable functions and predicates.
* **Inference & Reasoning**: Resolution, Natural deduction, Logic programming, Forward vs. Backward reasoning, Matching algorithms, Control knowledge.

#### 🔹 Unit 3: Game Playing & Planning
* **Game Playing**: Minimax search procedure, Adding Alpha-Beta (α-β) cutoffs, Game heuristic refinements.
* **Planning Systems**: Components of a planning system, Goal task planning, Nonlinear planning, Hierarchical planning.

#### 🔹 Unit 4: Natural Language Processing & Advanced AI
* **Understanding**: Understanding mechanisms, Understanding as constraint satisfaction.
* **Natural Language Processing (NLP)**: Syntactic processing, Unification grammars, Semantic analysis.
* **Advanced AI Topics**: Parallel and Distributed AI, Psychological modeling, Distributed reasoning systems.

---

### 🐘 Paper 1: 3T1 — Big Data Analytics
* **Credits**: 4 | **Theory Marks**: 80 External + 20 Internal = 100 Marks

#### 🔹 Unit 1: Big Data Overview & Hadoop Ecosystem
* **Big Data Concepts**: What is Big Data, History of data management, Structuring Big Data, Elements, Analytics advantages & use cases.
* **Distributed Computing**: Distributed and parallel computing in Big Data, Introduction to Hadoop, HDFS and MapReduce, Cloud computing and Big Data features.
* **Hadoop Architecture & Ecosystem**: HDFS Architecture, HDFS Commands, MapReduce, Hadoop YARN, HBase Architecture, Combining HBase & HDFS, Hive, Pig & Pig Latin, Sqoop, ZooKeeper, Flume, Oozie.
* **MapReduce & HBase**: MapReduce framework, Features, Working, Job optimization techniques, Uses.

#### 🔹 Unit 2: Big Data Technology Stack & Storage
* **Big Data Stack**: Data Source Layer, Ingestion Layer, Storage Layer, Physical Infrastructure Layer, Platform Management, Security, Monitoring, Visualization Layer, Big Data applications, Virtualization approaches.
* **Databases & Warehouses**: RDBMS vs. Big Data, CAP Theorem, Issues with relational models, Non-relational databases (NoSQL), Integrating Big Data with traditional Data Warehouses.

#### 🔹 Unit 3: Data Analytics with R
* **Exploring R**: Basic & statistical features, Packages, R Console, RStudio, Basic arithmetic, Variables & functions, Data in R workspace.
* **Datasets I/O**: `c()`, `scan()`, reading large data files, reading from RStudio, exporting data.
* **Data Processing in R**: Creating subsets, merging datasets, sorting, managing matrices and data frames.
* **Functions & Graphics**: Built-in functions, custom functions, packages, plotting and saving graphs.

#### 🔹 Unit 4: Visualization & Modern Analytics
* **Data Visualization**: Techniques, types, applications, big data visual tools.
* **Social Media Analytics & Text Mining**: Text mining processes, Sentiment analysis.
* **Mobile Analytics**: Definitions, tools, workflows, and challenges.

---

### ⛏️ Paper 2: 3T2 — Data Mining
* **Credits**: 4 | **Theory Marks**: 80 External + 20 Internal = 100 Marks

#### 🔹 Unit 1: Foundations & Preprocessing
* **Introduction**: Data mining tasks, origins, motivating challenges, data quality, attribute types & measurement.
* **Data Preprocessing**: Aggregation, Sampling, Dimensionality reduction, Feature subset selection, Feature creation, Discretization & Binarization, Variable transformation.

#### 🔹 Unit 2: Data Exploration & Classification (Part 1)
* **Exploring Data**: Iris dataset, Summary statistics (Mean, Median, Range, Variance, Percentiles), Multidimensional visualization (Histograms, Box plots, Scatter plots, Contour plots, Parallel coordinates), OLAP.
* **Classification Basics**: Decision Tree induction, Model evaluation, Overfitting, Performance metrics, Comparing classifiers.

#### 🔹 Unit 3: Advanced Classification & Association Analysis
* **Advanced Classifiers**: Rule-based classifiers, Nearest Neighbor (k-NN), Bayesian Classifiers & Naive Bayes, Artificial Neural Networks (ANN), Support Vector Machines (SVM).
* **Association Rule Mining**: Problem definition, Apriori algorithm, Candidate generation & pruning, Support counting, FP-Growth algorithm, FP-Tree representation.

#### 🔹 Unit 4: Cluster Analysis & Anomaly Detection
* **Clustering**: K-Means and variants, Hierarchical clustering, Density-based clustering (DBSCAN), Graph-based clustering, Shared Nearest Neighbor (SNN), Jarvis-Patrick.
* **Anomaly Detection**: Causes, Statistical approaches, Proximity-based outlier detection, Density-based & Clustering-based techniques.

---

### 🐍 Paper 3: 3T3 — Python Programming
* **Credits**: 4 | **Theory Marks**: 80 External + 20 Internal = 100 Marks

#### 🔹 Unit 1: Python Basics, Functions & OOP
* **Fundamentals**: Object types, Operators, Numbers, Strings, Lists, Tuples, Dictionaries, Files, Type conversion, Control statements.
* **Functions & Modules**: Scoping & LGB rule, Keyword arguments, Default arguments, `*args`, `**kwargs`, `map()`, `lambda` functions, Modules & Packages.
* **OOP & Exceptions**: Classes, Instances, Methods, Built-in & custom exceptions.

#### 🔹 Unit 2: Built-ins & OS Interfacing
* **Built-in Functions**: `__import__()`, `getattr()`, `setattr()`, `hash()`, `id()`, `isinstance()`, `type()`, `str()`.
* **OS & System**: `sys` module, `os` module, Multithreading, String & text manipulation, Unicode, Time manipulation.

#### 🔹 Unit 3: File Handling, Network & RAD
* **File Operations**: Reading/writing, file positions, file locking, permissions, directory management.
* **Network & Media**: Creating network servers & clients, multimedia (Audio/Graphic modules).
* **Rapid App Development**: Standard library, distribution using `distutils`.

#### 🔹 Unit 4: Web Development & Architecture
* **Web Basics**: CGI scripting, Dynamic websites, Cookies, Security.
* **Markup Processing**: SGML, HTML, XML processing.
* **Python Architecture**: Namespaces, Code blocks, Frames, Bytecode disassembly & opcodes, Jython, Python.NET.

---

### 🧠 Paper 5: 3T5 — Soft Computing
* **Credits**: 4 | **Theory Marks**: 80 External + 20 Internal = 100 Marks

#### 🔹 Unit 1: Search & Statistical Reasoning
* **Introduction**: Soft vs. Hard computing, Computational Intelligence.
* **Search & Reasoning**: BFS, DFS, Best-First, A* Algorithm, AO* Algorithm, Minimax with Alpha-Beta pruning, Iterative deepening, Bayesian networks, Dempster-Shafer theory.

#### 🔹 Unit 2: Artificial Neural Networks (ANN)
* **ANN Basics**: Biological vs. Artificial neuron, McCulloch-Pitts model, Activation functions, Hebbian learning, Perceptron learning, Widrow-Hoff / Delta rule.
* **Multilayer Networks**: Multilayer Perceptron (MLP), Backpropagation Network (EBPA derivation), Adaline, Madaline, Momentum.

#### 🔹 Unit 3: Advanced Neural Networks
* **Unsupervised Networks**: Counterpropagation network, Hopfield network, Bidirectional Associative Memory (BAM).
* **Self-Organizing & Kernel Systems**: Adaptive Resonance Theory (ART), Support Vector Machines (SVM), Kohonen Self-Organizing Maps (SOM).

#### 🔹 Unit 4: Fuzzy Logic & Systems
* **Fuzzy Fundamentals**: Crisp vs. Fuzzy sets, Membership functions, Fuzzy relations, Interval arithmetic.
* **Fuzzy Rule Base**: Fuzzy propositions, reasoning, inference engines, Fuzzification & Defuzzification methods, Fuzzy Associative Memory (FAM), Fuzzy control systems.
