* **Text Manipulation:** String slicing, searching, splitting, joining, regex parsing, and formatting over immutable Unicode strings (`str`).

## ⚙️ 3. In-Depth Technical Breakdown & Working Mechanism

### Part (i): Number Manipulation In-Depth
- **Arbitrary Precision Integers:** In Python 3, `int` has unbounded precision; it automatically expands memory dynamically to prevent integer overflow.
- **The `math` Module:**
  * `math.floor(x)` / `math.ceil(x)`: Rounding down and up to nearest integer.
  * `math.sqrt(x)`, `math.pow(x, y)`, `math.log(x, base)`: Power and logarithmic calculus.
- **The `random` Module:**
  * `random.randint(a, b)`: Generates a random integer in $[a, b]$.
  * `random.choice(seq)`: Randomly samples an element from a sequence.

---

### Part (ii): Text Manipulation In-Depth
- **String Immutability:** Python strings cannot be modified in place; all string manipulation methods return brand new string instances.
- **Core String Methods:**
  * `.strip()`: Strips leading and trailing whitespace/characters.
  * `.split(delimiter)`: Tokenizes a string into a list of substrings.
  * `.join(iterable)`: High-performance concatenation of string lists using a delimiter.
  * `.replace(old, new, count)`: Replaces occurrences of a substring.
  * `.startswith(prefix)` / `.endswith(suffix)`: Fast prefix/suffix verification.
- **Modern String Formatting (f-Strings):**
  Formatted string literals (`f"Hello {name}, balance: {amt:.2f}"`) evaluate expressions directly at runtime with minimal overhead.

## 💻 6. Implementation Syntax, Algorithm & Code Mechanics

### Comprehensive Working Python Script:
```python
import math, random

# 1. Number Manipulation
radius = random.uniform(2.5, 10.0)
area = math.pi * math.pow(radius, 2)
print(f"Radius: {radius:.2f} | Area: {math.ceil(area)}")

# 2. Text Manipulation
raw_log = "  ERROR: 2026-09-30: Database Connection Timeout!  "
cleaned = raw_log.strip()
tokens = cleaned.split(": ")
log_level = tokens[0]
message = tokens[2].replace("Timeout", "Refused")

formatted_report = f"[{log_level.upper()}] Details -> {message}"
print(formatted_report)
```

## ⚖️ 7. Key Advantages, Challenges & Limitations

* **Numbers:** Unbounded integer size avoids C-style buffer overflows; floating-point representation is subject to IEEE-754 precision limits.
* **Text:** Memory-efficient string interning; repetitive concatenation in loops using `+` creates $O(N^2)$ memory bloat (always use `''.join()`).
