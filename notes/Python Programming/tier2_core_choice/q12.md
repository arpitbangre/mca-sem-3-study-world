## 🎯 1. Core Technical Definition & Foundations

In computing, number systems represent values using different positional radix bases:
* **Decimal (Base-10):** Standard human counting system utilizing digits $[0-9]$.
* **Octal (Base-8):** Utilizes 8 discrete digits $[0-7]$, grouping binary representations into 3-bit clusters ($2^3 = 8$). Prefix in Python: `0o`.
* **Hexadecimal (Base-16):** Utilizes 16 symbols $[0-9, A-F]$, grouping binary representations into 4-bit nibbles ($2^4 = 16$). Prefix in Python: `0x`.

## ⚙️ 3. In-Depth Technical Breakdown & Working Mechanism

### 1. Python Built-in Radix Conversion Primitives
* **`oct(x)`:** Converts an integer $x$ into its octal string representation prefixed with `'0o'`. E.g., `oct(45)` yields `'0o55'`.
* **`hex(x)`:** Converts an integer $x$ into its hexadecimal string representation prefixed with `'0x'` in lowercase. E.g., `hex(45)` yields `'0x2d'`.
* **`bin(x)`:** Converts to binary prefixed with `'0b'`.
* **String Formatting Alternatives:**
  * Using `format()`: `format(num, 'o')` (unprefixed octal), `format(num, 'X')` (uppercase hex without prefix).
  * Using f-Strings: `f"{num:#o}"` and `f"{num:#X}"`.

### 2. Manual Mathematical Conversion Algorithm
To prove algorithmic mastery in the RTMNU examination, the student should provide both the built-in approach AND the manual iterative remainder division algorithm:
1. Divide the decimal integer by target base ($8$ or $16$).
2. Record the remainder (for Base-16, map remainders $10-15$ to characters `'A'-'F'`).
3. Update integer using integer floor division: $n = n // \text{base}$.
4. Repeat until quotient is $0$, then reverse the sequence of remainders.

## 💻 6. Implementation Syntax, Algorithm & Code Mechanics

### Complete, Production-Grade Python Program:
```python
def manual_convert(num, base):
    """Manual base conversion using repeated division algorithm"""
    if num == 0:
        return "0"
    digits = "0123456789ABCDEF"
    result = []
    n = abs(num)
    while n > 0:
        remainder = n % base
        result.append(digits[remainder])
        n = n // base
    if num < 0:
        result.append("-")
    return "".join(reversed(result))

def main():
    print("=" * 55)
    print("  RTMNU MCA SEM 3: NUMBER SYSTEM CONVERSION SYSTEM")
    print("=" * 55)
    
    try:
        user_input = input("Enter an integer number: ").strip()
        decimal_val = int(user_input)
        
        # 1. Method A: Built-in Conversion Functions
        oct_builtin = oct(decimal_val)
        hex_builtin = hex(decimal_val).upper()
        
        # 2. Method B: Modern f-string Formatting
        oct_formatted = f"{decimal_val:#o}"
        hex_formatted = f"{decimal_val:#X}"
        
        # 3. Method C: Algorithmic Verification
        oct_manual = manual_convert(decimal_val, 8)
        hex_manual = manual_convert(decimal_val, 16)
        
        print("
--- CONVERSION REPORT ---")
        print(f"Decimal Value Entered : {decimal_val}")
        print(f"Octal Equivalent      : {oct_formatted} (Manual: {oct_manual})")
        print(f"Hexadecimal Equivalent: {hex_formatted} (Manual: {hex_manual})")
        print(f"Binary Equivalent     : {bin(decimal_val)}")
        print("=" * 55)
    except ValueError:
        print("[ERROR]: Invalid input! Please enter a valid integer.")

if __name__ == "__main__":
    main()
```
