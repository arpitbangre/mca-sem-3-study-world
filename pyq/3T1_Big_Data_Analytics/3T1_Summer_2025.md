## Question Paper Content

> **Note:** (1) All questions are compulsory and carry equal marks. (2) Draw neat and labelled diagrams wherever necessary.

### Question 1 (Unit I) [16 Marks]
#### EITHER
- **a)** What is Big Data? Explain different types and characteristics of big data. `[8 Marks]`
- **b)** What is distributed computing? Explain the working of distributed computing environment. `[8 Marks]`

#### OR
- **c)** Explain different component of Hadoop ecosystem. `[8 Marks]`
- **d)** Write a short notes on-
  i) HDFS
  ii) MapReduce `[8 Marks]`

### Question 2 (Unit II) [16 Marks]
#### EITHER
- **a)** Write a short notes on-
  i) Server Virtualization
  ii) Application Virtualization `[8 Marks]`
- **b)** Differentiate between relational database system and big data solutions. `[8 Marks]`

#### OR
- **c)** Explain the terms-
  i) Physical infrastructure layer
  ii) Platform Management layer `[8 Marks]`
- **d)** What are the three properties of the CAP Theorem? Describe each briefly. `[8 Marks]`

### Question 3 (Unit III) [16 Marks]
#### EITHER
- **a)** Explain the working of scan( ) command in R. `[8 Marks]`
- **b)** Explain the terms:
  i) Sorting data
  ii) Ordering data `[8 Marks]`

#### OR
- **c)** What are packages? Write down the steps to install packages in R. `[8 Marks]`
- **d)** What are basic plotting function in R? And how do you create Scatter plots, histograms and bar charts? `[8 Marks]`

### Question 4 (Unit IV) [16 Marks]
#### EITHER
- **a)** What is data visualization? Explain the tools used in data visualization. `[8 Marks]`
- **b)** Write a short notes on-
  i) Sentiment analysis
  ii) Social media `[8 Marks]`

#### OR
- **c)** What is mobile analytics? Discuss some field where mobile analytics can be used. `[8 Marks]`
- **d)** What are the main types of Data Visualizations? And when are they used? Explain. `[8 Marks]`

### Question 5 (Compulsory / Short Notes) [16 Marks - 4 Marks Each]
- **a)** What is Big Data Analytics? Explain it's types. `[4 Marks]`
- **b)** What is a non-relational database? Explain. `[4 Marks]`
- **c)** Explain advance features in R. `[4 Marks]`
- **d)** What techniques are used to analyze text data? Explain. `[4 Marks]`
