## Question Paper Content

> **Note:** (1) All questions are compulsory and carry equal marks. (2) Draw neat and labelled diagrams wherever necessary.

### Question 1 (Unit I) [16 Marks]
#### EITHER
- **a)** What is Data Mining? Explain the origin of Data Mining. `[8 Marks]`
- **b)** Write a note on:
  i) Feature creation
  ii) Feature subset selection `[8 Marks]`

#### OR
- **c)** What are motivating challenges in Data Mining? `[8 Marks]`
- **d)** Write short note on:
  i) Types of Dataset
  ii) Data Mining Tasks. `[8 Marks]`

### Question 2 (Unit II) [16 Marks]
#### EITHER
- **a)** Explain Decision Tree induction with suitable example. `[8 Marks]`
- **b)** Explain the terms:
  i) Measures of location
  ii) Measures of spread `[8 Marks]`

#### OR
- **c)** What is visualization? Explain different visualization techniques in data mining. `[8 Marks]`
- **d)** What is OLAP? Explain multidimensional analysis in detail. `[8 Marks]`

### Question 3 (Unit III) [16 Marks]
#### EITHER
- **a)** What is classification? Explain any two classification techniques in detail. `[8 Marks]`
- **b)** Explain Apriori Algorihtm in detail. `[8 Marks]`

#### OR
- **c)** Explain FP Growth Algorithm with suitable example. `[8 Marks]`
- **d)** Explain the terms:
  i) Support vector machine
  ii) Naïve Bayes classifier `[8 Marks]`

### Question 4 (Unit IV) [16 Marks]
#### EITHER
- **a)** Explain different causes of Anomaly detection. Explain the proximity based outlier detection. `[8 Marks]`
- **b)** Explain density based clustering in detail. `[8 Marks]`

#### OR
- **c)** What is cluster Analysis? Write different types of clustering in detail. `[8 Marks]`
- **d)** Explain the different clustering Algorithms. Explain k-means clustering in detail. `[8 Marks]`

### Question 5 (Compulsory / Short Notes) [16 Marks - 4 Marks Each]
- **a)** What is Data Quality? Explain data collection issues. `[4 Marks]`
- **b)** Explain evaluating the performance of a classifier in Data Mining. `[4 Marks]`
- **c)** Write a note on Bayesian classifier. `[4 Marks]`
- **d)** Explain graph based clustering with a suitable example. `[4 Marks]`
