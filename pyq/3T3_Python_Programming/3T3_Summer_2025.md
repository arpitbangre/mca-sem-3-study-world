## Question Paper Content

> **Note:** (1) All questions are compulsory and carry equal marks. (2) Draw neat and labelled diagrams wherever necessary.

### Question 1 (Unit I) [16 Marks]
#### EITHER
- **a)** Explain Exception handling in detail with examples. `[8 Marks]`
- **b)** Write a short notes on-
  i) Argument tuples
  ii) Argument dictionaries `[8 Marks]`

#### OR
- **c)** What are the basic list operation that can be performed in python. Explain it’s operation with it’s syntax. `[8 Marks]`
- **d)** What is dictionary? Explain Python dictionary in detail. `[8 Marks]`

### Question 2 (Unit II) [16 Marks]
#### EITHER
- **a)** Explain built in function in Python. `[8 Marks]`
- **b)** Explain working with the system (Sy module) in detail. `[8 Marks]`

#### OR
- **c)** Write a notes on-
  i) Manipulating numbers
  ii) Text manipulation `[8 Marks]`
- **d)** Explain how Python’s time module can be used to manipulate time related information. How do functions like time.sleep( ) and time.time( ) work. `[8 Marks]`

### Question 3 (Unit III) [16 Marks]
#### EITHER
- **a)** Discuss file processing in Python. How can files be read from and written to in Python? Explain different modes of file handling. `[8 Marks]`
- **b)** Write a short notes on-
  i) File control
  ii) File locking `[8 Marks]`

#### OR
- **c)** Explain working with SMTP and FTP in client module. `[8 Marks]`
- **d)** Discuss how Python can be used for multimedia processing, specifically for handling audio and graphics. `[8 Marks]`

### Question 4 (Unit IV) [16 Marks]
#### EITHER
- **a)** Write a short notes on-
  i) Cookies
  ii) Python server pages `[8 Marks]`
- **b)** Explain processing SGML and processing XML in detail. `[8 Marks]`

#### OR
- **c)** What is Python bytecode? Discuss the process of compiling Python code into bytecode and how it is executed by python interpreter. `[8 Marks]`
- **d)** What is Uniform Resource Locator (URL)? Explain it’s structure and how it is used to access resource on the web. `[8 Marks]`

### Question 5 (Compulsory / Short Notes) [16 Marks - 4 Marks Each]
- **a)** Write a short note on LGB rule. `[4 Marks]`
- **b)** What is thread? Explain thread control and object locking. `[4 Marks]`
- **c)** Explain the term Python standard library. `[4 Marks]`
- **d)** Write a note on socket server. `[4 Marks]`
