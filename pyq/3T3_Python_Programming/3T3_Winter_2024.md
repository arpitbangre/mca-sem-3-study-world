## Question Paper Content

> **Note:** (1) All questions are compulsory and carry equal marks. (2) Draw neat and labelled diagrams wherever necessary.

### Question 1 (Unit I) [16 Marks]
#### EITHER
- **a)** What are lists and types? Explain the difference between them. `[8 Marks]`
- **b)** What are the common built-in data types in Python? `[8 Marks]`

#### OR
- **c)** What is dictionary? Explain Python dictionaries in detail discussing their operations and methods. `[8 Marks]`
- **d)** Explain in detail various control statement used in Python. `[8 Marks]`

### Question 2 (Unit II) [16 Marks]
#### EITHER
- **a)** Write a program to enter a number in Python and print its octal and hexadecimal equivalent. `[8 Marks]`
- **b)** Explain any five built-in functions in Python. `[8 Marks]`

#### OR
- **c)** Explain in detail multithreading in Python. `[8 Marks]`
- **d)** Write note on Unicode strings. `[8 Marks]`

### Question 3 (Unit III) [16 Marks]
#### EITHER
- **a)** Explain File Processing in detail. `[8 Marks]`
- **b)** Write note on controlling file I/O. `[8 Marks]`

#### OR
- **c)** Explain in detail setting file permission and manipulating file paths. `[8 Marks]`
- **d)** Write a note on:
  i) Audio modules
  ii) Graphic modules `[8 Marks]`

### Question 4 (Unit IV) [16 Marks]
#### EITHER
- **a)** Write a note on Security. `[8 Marks]`
- **b)** Write a note on processing XML in Python. `[8 Marks]`

#### OR
- **c)** Explain in detail Python execution structure. `[8 Marks]`
- **d)** Explain Namespaces, Code Blocks and Frames. `[8 Marks]`

### Question 5 (Compulsory / Short Notes) [16 Marks - 4 Marks Each]
- **a)** What is an exception? Explain with example. `[4 Marks]`
- **b)** Write a note on text manipulation. `[4 Marks]`
- **c)** Write note on Handling Internet Data. `[4 Marks]`
- **d)** Explain Cookies in detail. `[4 Marks]`
