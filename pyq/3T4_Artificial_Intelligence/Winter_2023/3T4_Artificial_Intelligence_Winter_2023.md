## 💡 Exam Answer Writing Best Practices (RTMNU Evaluation Standard)
1. **For 8-Mark Questions:**
   - Begin with formal definition & core purpose (1-2 marks).
   - Provide a clear labelled architectural block diagram / flow chart (2 marks).
   - Provide step-by-step algorithm / mathematical formula / working mechanism (3 marks).
   - Include concrete numerical example / code trace / use case (1-2 marks).
2. **For 4-Mark Questions (Q5):**
   - Write concise, point-wise explanation (4 to 6 strong technical bullet points).
   - Include small diagram / syntax block where applicable.
