## Question Paper Content

> **Note:** (1) All questions are compulsory and carry equal marks. (2) Draw neat and labelled diagrams wherever necessary.

### Question 1 (Unit I) [16 Marks]
#### EITHER
- **a)** What is soft computing? Explain difference between soft computing and hard computing. `[8 Marks]`
- **b)** Explain in detail AO* Algorithms. `[8 Marks]`

#### OR
- **c)** Write a short notes on:
  i) Bayesian networks.
  ii) Dempster Shafer Theorem. `[8 Marks]`
- **d)** Describe Breath First-Search (BFS) algorithms in detail. `[8 Marks]`

### Question 2 (Unit II) [16 Marks]
#### EITHER
- **a)** Describe the biological neural network and explain the structure and functioning of the human brain. `[8 Marks]`
- **b)** Explain:
  1) Supervised learning
  2) Unsupervised learning `[8 Marks]`

#### OR
- **c)** What is perceptron? Explain single layer and multilayer perceptron in detail. `[8 Marks]`
- **d)** Explain backpropagation network, including the derivation of the Error Back Propagation Algorithm (EBPA) `[8 Marks]`

### Question 3 (Unit III) [16 Marks]
#### EITHER
- **a)** What is Counter Propagation Network (CPN)? Explain the architecture of a counter propagation network. `[8 Marks]`
- **b)** Explain the architecture of Adaptive Resource Theory (ART) model. `[8 Marks]`

#### OR
- **c)** Explain Kohonen’s Self Organizing Map (SOM) in detail. `[8 Marks]`
- **d)** Write a short notes on:
  i) Associative memory
  ii) Support Vector Machine (SVM) `[8 Marks]`

### Question 4 (Unit IV) [16 Marks]
#### EITHER
- **a)** Define Fuzzy sets and explain operations on Fuzzy sets with examples. `[8 Marks]`
- **b)** Define fuzzification and explain it’s importance in fuzzy systems. `[8 Marks]`

#### OR
- **c)** Explain membership function in Fuzzy logic system. `[8 Marks]`
- **d)** Explain Fuzzy associative memory in detail. `[8 Marks]`

### Question 5 (Compulsory / Short Notes) [16 Marks - 4 Marks Each]
- **a)** Discuss the graph representation of search problem. `[4 Marks]`
- **b)** Explain Hebbian learning with an example. `[4 Marks]`
- **c)** Explain characteristics and application of Hopfield network. `[4 Marks]`
- **d)** Write a notes on Fuzzy reasoning. `[4 Marks]`
