## Question Paper Content

> **Note:** (1) All questions are compulsory and carry equal marks. (2) Draw neat and labelled diagrams wherever necessary.

### Question 1 (Unit I) [16 Marks]
#### EITHER
- **(A)** Define soft computing. Explain difference between soft-computing and hard-computing. `[8 Marks]`
- **(B)** Write notes on :
  (i) Alpha-beta cutoff
  (ii) Iterative deepening. `[8 Marks]`

#### OR
- **(C)** What is searching techniques ? Explain Best First Search (BFS) with example. `[8 Marks]`
- **(D)** Explain in detail AO* algorithm. `[8 Marks]`

### Question 2 (Unit II) [16 Marks]
#### EITHER
- **(A)** What are the various applications of Neural Network ? Explain. `[8 Marks]`
- **(B)** What is perceptron ? Explain single layer and multilayer perception in detail. `[8 Marks]`

#### OR
- **(C)** What is the difference between ANN and human brain ? Explain. `[8 Marks]`
- **(D)** Write notes on :—
  (i) Adaline
  (ii) Madaline. `[8 Marks]`

### Question 3 (Unit III) [16 Marks]
#### EITHER
- **(A)** Define Counter Propagation Network. Write the characteristics of counter propagation network. `[8 Marks]`
- **(B)** Explain Kohanan’s-self organizing map and its algorithm. `[8 Marks]`

#### OR
- **(C)** Explain hope-field network in detail. `[8 Marks]`
- **(D)** Write notes on :—
  (i) Associative Memory
  (ii) Bidirectional Associative Memory. `[8 Marks]`

### Question 4 (Unit IV) [16 Marks]
#### EITHER
- **(A)** What is fuzzy set theory ? Write its operations. `[8 Marks]`
- **(B)** Explain membership function in fuzzy logic system. `[8 Marks]`

#### OR
- **(C)** What is fuzzy system ? Explain why we need fuzzy system. `[8 Marks]`
- **(D)** Write notes on :—
  (i) Fuzzy reasoning
  (ii) Fuzzy associative memory. `[8 Marks]`

### Question 5 (Compulsory / Short Notes) [16 Marks - 4 Marks Each]
- **(A)** Explain the concept of additional refinements. `[4 Marks]`
- **(B)** Explain Delta learning rule. `[4 Marks]`
- **(C)** Explain SVM in detail. `[4 Marks]`
- **(D)** Write the difference between fuzzification and defuzzification. `[4 Marks]`
