## 🎯 Examination Format & Pattern (80 Marks)

Every question paper adheres strictly to the official RTMNU scheme:
- **Duration:** 3 Hours
- **Maximum Marks:** 80
- **Question 1:** Unit I (EITHER a [8M] + b [8M] OR c [8M] + d [8M]) = **16 Marks**
- **Question 2:** Unit II (EITHER a [8M] + b [8M] OR c [8M] + d [8M]) = **16 Marks**
- **Question 3:** Unit III (EITHER a [8M] + b [8M] OR c [8M] + d [8M]) = **16 Marks**
- **Question 4:** Unit IV (EITHER a [8M] + b [8M] OR c [8M] + d [8M]) = **16 Marks**
- **Question 5:** Compulsory Short Notes (a, b, c, d at 4M each, one from each unit) = **16 Marks**
- **Grand Total:** 5 × 16 Marks = **80 Marks**
